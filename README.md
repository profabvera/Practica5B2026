### Aviso

Este espacio no es un repo de desarrollo propiamente dicho, se utiliza como un espacio de apoyo para el aprendizaje. Verá aquí explicaciones elementales y fragmentos de código destinado a aquellas personas que recien comienzan a programar en el lenguaje C++.  

Desde luego contiene errores o porciones de código que puede hacerse de forma más eficiente, pero aquí se prioriza en aprendizaje , quizá un programador experimentado o un especialista lo encararía de forma distinta. Pero dentro de las limitaciones y posibilidades tanto de los alumnos y del profesor he creído que es una opición bastante razonable utilizarlos.

-     Puntos a favor:
  
  - Concección directo con herramientas de desarrollo. La comprensión de como funciona un repositorio y la forma de trabajar está abriendo la puerta. Esto es de enorme potencial ya que sin que el profesor los indique, los alumnos pueden descubrirlo.
  
  - Es de acceso libre y gratuito. Si bien es posible hacerlo de forma privada, he decidido hacerlo público de modo tal que todos puedan acceder a la información que los alumnos incorporan. Con ello los alumnos no están obligados a dejar sus datos en la plataforma, eso no significa que no lo harán, pero no estarán coaccionadas.
  
  - Se utiliza solo software libre. La curva de aprendizaje es mayor, pero la comprensión también es mayor.
  
  - La libertad es un bien preciado y escaso, no se negocia, pero conlleva una **enorme responsabilidad.** Piense solamente el la **libertad 0** del software libre **utilizar el software para cualuier propósito** exige del usuario usar el software para un bien, aunque en ningún lado está escrito. Se asume que el usaurio de este tipo de software es, en primer lugar **responsable** y no usara el software para infrigir un daño.

- Puntos en contra:
  
  - Datos de alumnos en la nube. Al hacerlo de acceso libre el alumno no está obligado a dejar sus datos, pero igualmente se hace complejo trabajar de forma completamente anónima ya que las plataformas conservan el derecho de admisión razón por la cual, probablemente terminará usando dicha plataforma. Eso no es malo, pero no es legal, salvo concentimietno explícito del tutor.
  - Si no hay concección a Iternet noy hay acceso a la información. Se asume que hoy eso no es un problema, pero puede que algunos aún estén en esas condiciones.
