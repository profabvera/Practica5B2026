# Actividad 5b

Escribe un programa que muestre los números enteros mayores o iguales que **1** y menores que **100**, mostrando cada número en una línea independiente.

Además, cuando un número sea múltiplo de **7**, deberá aparecer a su lado la leyenda:

> **Es múltiplo de 7**

Para resolver esta actividad utiliza el ciclo **`while`**.

Luego, realiza dos versiones adicionales del mismo programa:

- **`act5b1`**, utilizando el ciclo **`do while`**.

- **`act5b2`**, utilizando el ciclo **`for`**.

Finalmente, compara las tres soluciones y analiza las similitudes y diferencias entre los ciclos **`while`**, **`do while`** y **`for`**.
