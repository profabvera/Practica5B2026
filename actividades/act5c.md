# Actividad 5c

Escribe un programa que solicite al usuario un número entero mayor o igual que **1** y menor o igual que **100**.

Si el número ingresado no cumple estas condiciones, el programa deberá mostrar el mensaje:

> **Número ingresado no válido**

y finalizar su ejecución.

Si el número ingresado es válido, el programa deberá contar la cantidad de divisores que posee.

Para resolver el problema, utiliza una variable entera, por ejemplo **`n`**, para almacenar el número ingresado, y otra variable entera llamada **`cantDiv`**, que contendrá la cantidad de divisores encontrados.

Finalmente, el programa deberá mostrar un mensaje con el siguiente formato:

> **El número `n` tiene `cantDiv` divisores.**

**Observación:** Antes de comenzar el algoritmo de búsqueda y conteo de divisores, es necesario validar que el número ingresado por el usuario cumpla con las condiciones establecidas.
